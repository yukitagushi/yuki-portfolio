AI System

補助金レコメンドシステム

Client
非公開（中小企業支援領域）
Year
2025
Category
AIシステム開発

Overview

事業内容・業種・規模・所在地などを入力すると、AIが該当する補助金・助成金候補を自動でレコメンドするシステム。制度情報を条件別に整理し、事業者が確認する候補を提示します。

Challenge

補助金制度ごとに要件・公募期間が異なるため、事業者や支援者が条件に合う情報を探し、比較する仕組みが必要でした。

Solution

補助金データをスクレイピング/API取得で取り込み、業種・規模・目的・地域などの条件で構造化。入力された事業プロファイルとマッチ度を計算し、上位候補に対してAIが「申請時に確認するポイント」「必要書類リスト」までセットで提案する設計にしました。

担当した内容

  • ✓事業情報をもとに補助金・助成金の候補を提示
  • ✓業種・地域・目的の条件に応じて制度の候補を表示
  • ✓申請のポイント・必要書類までAIが自動生成
  • ✓士業・経営コンサル向けにホワイトラベル提供も可能

Tech Stack

Next.js TypeScript Supabase OpenAI / Claude API スクレイピング基盤
