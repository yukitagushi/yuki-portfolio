Overview

AIで動画コンテンツを大量生成し、TikTok・Instagram上でAIインフルエンサーアカウントを運用するプロジェクト。画像生成 → 動画合成 でフォロワー1〜2万人を達成。

Challenge

ファーストビュー（最初の数秒）での離脱を防ぐため、実在する人物のようにとてもリアルな画像を生成し、自然な動画を作り出すことが課題でした。

Solution

画像生成、投稿文、返信文を自動的に生成する仕組みを構築。AIで生成したリアルな人物画像をベースに動画を合成し、投稿から運用までを自動化することで、複数アカウントの継続運用を実現しています。

Results

  • ✓複数アカウントでフォロワー1〜2万人を達成
  • ✓動画コンテンツの大量生成パイプライン構築（テーマ投入 → 完成動画）
  • ✓投稿文・返信文まで含めた運用フローを自動化

Tech Stack

Claude / GPT API Fish Audio (TTS) Remotion Nano Banana (画像生成) Python TikTok / Instagram

Service

この実績をもとにしたAIインフルエンサー制作・運用代行サービスを提供しています。キャラクター設計から動画量産・アカウント運用まで、貴社のSNSでも同じ仕組みを構築できます。
