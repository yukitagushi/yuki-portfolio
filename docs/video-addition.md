# トップの背景動画を追加するには

**動画を渡して「この動画をトップの背景に追加して」と依頼するだけで大丈夫です。** 掲載してよい動画ファイルまたはURLと、管理用の作品名を伝えてください。「最初に流して」「この動画の次に追加して」と順番も指定できます。

元ファイルは保管したまま、背景用の音声なし動画と静止画を別に用意します。トップでは映像が無音で自動的に切り替わります。映像内の見出しと「制作実績」は文字として表示し、一時停止・再開の操作を残します。動画一覧や全編を再生するページは作りません。

## 制作・運用担当者向け

`content/hero-videos.json` の `videos` 配列が背景映像の設定です。配列の順に再生し、末尾の次は先頭に戻ります。追加や並べ替えの後にトップページを再生成してください。JSON自体は公開せず、生成したHTMLと背景用メディアを公開します。

1. 元の完成動画を残し、音声トラックのないWeb用MP4またはWebMと、同じ縦横比のポスターを `uploads/videos/` に用意します。MP4はH.264とfaststartを使います。ファイル名や拡張子だけで形式・サイズを判断せず、実ファイルを確認します。
2. 下の形式で1件追加します。`src` は背景用動画のURL、`poster` は読み込み前や動きを減らす設定時に表示する静止画です。`width` と `height` には配信ファイルを測った値を指定します。
3. 生成・検証後にPCとスマートフォンで自動切替、縦横の表示、一時停止・再開、映像内の文字の読みやすさを確認します。動きを減らす設定とJavaScript無効時にはポスターと見出しが表示されることも確認します。

```json
{
  "videos": [
    {
      "slug": "new-work",
      "title": "管理用の作品名",
      "src": "/uploads/videos/new-work-background.mp4",
      "poster": "/uploads/videos/new-work-poster.webp",
      "width": 1920,
      "height": 1080
    }
  ]
}
```

これは形式の例です。ファイルとサイズは実物に合わせてください。`title` は素材を識別する管理名です。`slug` は任意の識別子で、ページのURLは生成しません。英小文字・数字・ハイフンを使い、既存の識別子と重複させないでください。全編URL、紹介文、公開日、全編の尺の登録は不要です。

### スマートフォンでの構図と字幕

任意の`mobileLayout`で、その動画の間だけスマートフォン表示を切り替えられます。

- `centered`: 横動画をスマートフォン（699px以下）で画面いっぱいに表示し、中央より少し左（46%）を基準に切り抜きます。大きい見出しだけ36px上げ、説明行は従来の位置を保ちます。現在の「ひと息ソーダ」に設定し、女性と雲の顔が見える構図にしています。
- `wide`: 横動画用。スマートフォンでも主映像の全画角を残し、その下に大きい見出しを配置します。現在は未使用。
- `captioned`: 映像の下寄りに字幕がある動画用。スマートフォン・小型タブレット（919px以下）でHTML見出しを小さい1行にして下へ移し、下端に陰影を入れます。現在はヘアケア広告に設定。
- `standard`または省略: 従来の表示。縦動画は全体を残し、見出しは大きい2行。

`captioned`は字幕位置を自動検出する機能ではありません。現在のヘアケア動画は字幕が高さ約55〜69%にあるため、この配置を使っています。新しい動画に設定するときは全編を確認し、字幕や商品と見出しが重ならないことを確認してください。`wide`の動画に合わせた高さは再生中の全動画で共有し、切り替えでページ下の位置が動かないようにしています。動画の順番を変えても、設定は作品に追従します。

```sh
python3 scripts/video_catalog.py
python3 scripts/build_home.py
python3 scripts/build_sitemap.py
python3 scripts/check_site.py
```

`video_catalog.py` は必須項目、管理名、動画・画像の拡張子、ローカル公開ファイルの実在、URL、サイズ、識別子の重複を確認します。外部メディアはHTTPSとファイル拡張子を検証し、通信と再生はブラウザで確認してください。YouTubeなどの視聴ページURLを `src` に指定することはできません。

背景から外すときは配列から削除してトップページを再生成します。不要になった配信用ファイルは、ほかの参照がないことを確認して公開対象から外します。Mac内の元ファイルはそのまま保管します。
