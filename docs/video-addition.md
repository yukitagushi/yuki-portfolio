# 動画作品を追加するには

**動画を渡して「この動画をポートフォリオに追加して」と依頼するだけで大丈夫です。** 動画ファイルまたは掲載してよい動画のURLと、表示したい作品名を伝えてください。「いちばん最初に流して」「この作品の後ろに追加して」と順番も指定できます。ページを毎回作り直す必要はありません。

元の動画を編集し直す必要はなく、サイト用に軽くした動画と静止画を別に用意します。ヒーローは無音で切り替わり、作品リンクから全編を見る構成です。作品を増やした後も、再生や表示を確認してから公開します。

## 制作・運用担当者向け

作品のデータは `content/hero-videos.json` の `videos` 配列で管理します。配列の先頭が最初に表示され、ヒーローと動画一覧には全作品、トップページの実績欄には先頭2作品を表示します。追加・並べ替え後にページを再生成してください。JSON自体は公開せず、生成したHTMLと配信用メディアを公開します。

1. 元ファイルを保管したまま、Webで再生できるMP4またはWebMと、同じ縦横比のJPEG・WebP等のポスターを `uploads/videos/` に用意します。MP4はH.264、必要ならAAC、先頭から再生できる配置（faststart）を使います。元ファイルの名前・拡張子だけで形式や音声の有無を判断せず、実ファイルを確認します。
2. 下の形式で作品を追加します。`width` と `height` は配信動画を測った値です。長い動画は短いヒーロー用動画を `previewSrc` に指定し、`src` に全編を指定できます。プレビューとポスターの縦横比は全編に揃えてください。
3. 生成・検証後、PCとスマートフォンで最初の表示、作品の切り替え、一時停止、全編の再生を確認します。

```json
{
  "videos": [
    {
      "slug": "new-work",
      "title": "作品の正式なタイトル",
      "description": "映像を確認して書いた作品紹介。",
      "src": "/uploads/videos/new-work.mp4",
      "previewSrc": "/uploads/videos/new-work-preview.mp4",
      "poster": "/uploads/videos/new-work-poster.webp",
      "href": "/videos/new-work.html",
      "width": 1920,
      "height": 1080,
      "durationSeconds": 20.04
    }
  ]
}
```

これは形式の例です。作品名・ファイル・サイズ・秒数は実物に合わせてください。`previewSrc` が不要なら省略できます。`slug`、`description`、`durationSeconds` は共通カタログでは任意です。新しい作品ページを生成する場合は `slug` を指定し、`href` を正確に `/videos/{slug}.html` に合わせます。既存のローカル作品ページへリンクする場合は `slug` を省略してください。HTTPSの `href` は外部作品ページへのリンクになり、サイト内の作品ページは生成しません。

`uploadDate` は公開日を確認できる場合だけ追加し、生成日やファイルの更新日時から推測しません。動画用の検索メタデータ（VideoObject）は、確認済みの公開日と動画の尺が揃った場合だけ生成します。

```sh
python3 scripts/video_catalog.py
python3 scripts/build_videos.py
python3 scripts/build_home.py
python3 scripts/build_sitemap.py
python3 scripts/check_site.py
```

`video_catalog.py` は必須項目、タイトル、動画・画像の拡張子、ローカル公開ファイルの実在、URL、サイズ、重複する識別名を確認します。生成前の作品ページはまだ存在しないことがあるため、リンク先の実在は生成後の `check_site.py` で確認します。外部メディアはHTTPSとファイル拡張子を検証し、実際の通信・再生はブラウザで確認してください。YouTubeなどの視聴ページURLは動画ファイルの `src` に使えません。

作品をヒーローと一覧から外すときは、配列から対象を削除して再生成します。以前に生成した作品ページとそのサイトマップ掲載は自動削除しません。動画やページを完全に非公開にする依頼の場合は、関連ページ・ファイルの削除や転送も対応し、サイトマップを再生成して公開状態を確認します。
