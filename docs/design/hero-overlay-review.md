# 採用画像と実装の比較

以下はヒーロー採用時点の比較記録。その後のユーザー指示で、トップの白いヘッダー帯をなくし、文字ロゴを映像内の左上へ移動した。ナビゲーションはPC・スマートフォン共通の二本線と白いメニューパネルに変更。1482／390／320pxの表示、開閉、キーボード、リンク移動を別途確認し、現行仕様は `design-system.md` に反映している。

参照：`hero-overlay-approved.png`。1482×1061のデスクトップと390×1000のスマートフォンを確認した。実映像は元動画のフレームを使用し、生成画像の描き直された商品や人物には置き換えない。

| 観点 | 参照と実装の確認 |
| --- | --- |
| 構成 | 白い約80pxのヘッダー直下に画面幅いっぱいの映像。見出しを上に置いた旧レイアウトを廃止。 |
| 見出し | 左下に「つくるを、」「もっと自由に。」の白い2行。副文は「AI広告動画の制作と、仕事の自動化。」で一致。 |
