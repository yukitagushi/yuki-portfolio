# Yuki Taguchi — サイトのデザイン仕様

ユーザーが採用した方針は、白と水色を基調に、本人のAI動画をトップの背景として見せる構成。映像の中に見出しと「制作実績」を置き、動画一覧や全編視聴への導線は設けない。緑中心の配色、ネオン、機械的な装飾を使わない。

## 配色と文字

白 `#FFFFFF`、水色 `#82D3EF`、淡い背景 `#F0FAFF`、本文 `#203645`、リンク `#106D95`、補足 `#557484`、罫線 `#D3EAF4`。コーラルは短い下線や工程番号に使う。水色のボタンと帯には濃色文字を使う。ヘッダーとフッターは名前を表示し、「Y」の四角いロゴは置かない。

日本語はシステムの角ゴシック。見出しは太め、本文は約1.9倍の行間。本文幅は最大1360px、モバイルの左右余白は20px。サービスと読みものは番号付きのリストと細い罫線で整理する。

## トップの背景映像

映像を画面の横幅いっぱいに表示する。映像内の左上に `SELECTED WORKS / 制作実績`、左下に「つくるを、もっと自由に。」と短いサービス説明を白いHTML文字で重ねる。文字は映像へ焼き込まず、下部の暗いグラデーションで読みやすさを補う。画像生成で採用された重ね方を基準とし、実装には本人が指定した動画と実フレームのポスターを使う。

映像枠はPCで540〜900pxの可変高さ、699px以下では560px。横映像は `cover` で背景全体を満たし、スマートフォンでは被写体に合わせて表示位置を調整する。縦映像は `contain` で全体を残し、余白に同じ作品のポスターをぼかして敷く。作品が切り替わっても映像枠の高さは変えない。

右下に現在位置、静かな3本の進捗バー、一時停止・再開ボタンを置く。バーは表示専用で、作品選択、前後移動、全編リンクは設けない。映像部分は読み上げ対象から外し、見出しと操作は独立したHTMLとして読み上げ・キーボード操作に対応する。映像の下には短い説明と相談への導線を置く。

## 背景の再生と素材管理

`content/hero-videos.json` の配列順で、音声トラックのない約8秒の背景用MP4を再生する。通常は約8秒、または動画の終端で次へ切り替え、約650msでフェードする。一時停止した状態を保ち、画面外・非表示タブでも停止する。動きを減らす設定やデータ節約では自動再生せず、再開ボタンを使えるようにする。読み込み失敗やJavaScript無効時にも、ポスターと見出しは表示する。

現在の3本は「ひと息ソーダ」AI CM、ヘアケア商品の縦型AI広告、日常を切り取る実写風POV動画。各項目は `title`、`src`、`poster`、`width`、`height` と任意の `slug` だけで管理する。全編ページのURLや公開日、紹介文は登録しない。追加方法は `../video-addition.md` を参照。

動画一覧と3つの全編視聴ページ、その生成処理と関連リンクは撤去した。元の完成動画はMac内に保管し、Web公開対象には背景用の短い音声なしファイルだけを置く。動画が未指定なら静止画 `uploads/creative-paper-sky.webp` を使う。

## 下層と導線

サービス5項目、Web・アプリ開発の案内、開発実績、AI活用ガイド、相談から運用まで、FAQ、水色の相談帯、メール作成フォーム、フッターを配置する。ホームの実績欄はシステム等の開発事例とし、動画作品のカードや動画一覧へのリンクは置かない。既存のサービス説明と開発実績ページは維持する。

フォームはメールアプリを開くための下書きを作る機能。サイト上で送信したとは表示しない。キーボード操作、フォーカス、モバイルメニューを維持する。実績の数値やお客様の声は捏造しない。
