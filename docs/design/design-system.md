# Yuki Taguchi — サイトのデザイン仕様

ユーザーの最新指定：白と水色。緑や白黒中心の配色を避け、AIらしいネオンや機械的な装飾を使わない。トップには本人が制作し、掲載用に指定したAI動画を順番に見せる。

## 配色と文字

白 `#FFFFFF`、水色 `#82D3EF`、淡い背景 `#F0FAFF`、本文 `#203645`、リンク `#106D95`、補足 `#557484`、罫線 `#D3EAF4`。コーラルは短い下線と工程番号、黄色は相談ボタンに限定する。水色のボタン・帯には濃色文字を使う。水色と本文のコントラストは約7.47:1、白とリンクは約5.76:1。

日本語はシステムの角ゴシック。見出しは太め、本文は約1.9倍の行間。コンテンツ幅は最大1360px、モバイルの左右余白は20px。サービスと読みものは番号付きの横並びリストと細い罫線で整理する。

## トップの動画

PCは左に見出し・説明・相談導線、右に大きな16:9の映像枠。映像の下に作品名、実績へのリンク、一時停止、前後移動、作品選択を置く。モバイルは見出し→映像→説明・相談導線の順にする。映像に色をかぶせず、縦動画も切り抜かず表示する。

動画ソースの定義は `content/hero-videos.json`。各作品のtitle、src（MP4/WebM）、poster、width、height、href（作品ページ）を指定して `python3 scripts/build_home.py` を実行する。素材の指定がない段階ではリストを空にし、実動画のように見せる仮作品を掲載しない。現在は掲載対象のURL・保存フォルダをユーザーへ確認中。

通常は無音で再生して約8秒ごと、または映像の終端で次の作品へ切り替える。切り替えは約650msのフェード。利用者が止めた場合は、その後も停止を保つ。画面外・非表示タブでは一時停止。動きを減らす設定やデータ節約では自動再生せず、手動再生を用意する。動画取得や再生に失敗してもポスターと作品リンクを維持する。

動画未指定時の静止画とSNSシェア画像は `uploads/creative-paper-sky.webp`。画像生成で従来の紙の造形を水色へ変更。形・質感・コーラルと黄色の紙は維持した。
