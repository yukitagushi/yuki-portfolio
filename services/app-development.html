アプリ・システム開発

No-code（Bubbleなど）とコード開発、そしてAIを組み合わせ、必要十分なアプリ・業務システムを短期間で形にします。
検証段階のMVP・社内向けの業務ツール・継続運用するプロダクトなど、目的に合わせて適切な作り方を選びます。

要件確認後にご案内 No-code + Code 併用 AI機能の組み込み対応

つくれるもの

記録・トラッキング系アプリ

日々のデータを記録・可視化・共有するアプリ。実際に片頭痛記録アプリを自社運用しています。

マッチング・予約系アプリ

利用者と提供者をつなぐマッチング機能、予約フロー、メッセージング機能などを実装。

ECサイト・商品販売システム

商品登録・在庫管理・決済を備えたECサイト。Shopify・自作の両方に対応。

業務システム（社内向け）

受発注・会計・顧客管理など、社内業務を支えるシステム。既存ツールとの連携も可能。

AI機能を組み込んだアプリ

Claude / GPT API を使った要約・分類・チャットなど、AI機能をプロダクトに組み込み。

MVP・プロトタイプ

事業仮説の検証のため、最小限の機能でまず動くものを作り、ユーザー検証へ進められます。

費用の目安

対象を絞った小規模な業務アプリの標準料金です。全社基幹システムや市販会計ソフト全体の置き換えは対象外です。料金はすべて税別で、最終金額と納品範囲は着手前の見積書で確定します。

費用区分料金標準範囲含まないもの・追加条件
試作・要件整理 50,000円 1業務・主要3画面まで。サンプルデータでの試作、軽微な修正1回、打ち合わせ合計90分まで。 本番データを扱う運用は含みません。試作のみで終了できます。
本番化 追加150,000円〜 業務画面3画面まで、標準ログイン、基本的な登録・一覧・検索・編集・保存、管理者・一般利用者の2区分、CSV出力または定型帳票1形式。権限確認、テスト、設置、基本操作の説明を含みます。 標準範囲なら試作と合わせて初期合計200,000円。AI機能、外部連携、複雑な処理などは別途見積もりです。
基本運用 月額4,000円 合意した利用人数・容量・処理量の枠内でのクラウド利用と基本運用。 初期開発費は別です。定例打ち合わせ、個別相談、機能・帳票の変更、利用枠超過は含みません。

AIスタンダード 月額総額12,000円 基本運用4,000円を含む総額。AI機能維持とAI利用枠3,000円分を含みます。 AI機能の初期開発費と個別の精度改善・機能追加は別です。
標準範囲の初期合計は200,000円です。 初期開発費と月額運用費は別です。画面数以内でも、AI機能・外部連携・複雑な計算や承認フローなどは標準範囲に含みません。利用人数・容量・処理量、月額の課金開始日、保守範囲は運用開始前に確定します。

料金・試作・AI機能のよくある質問

Q標準範囲の初期合計200,000円には何が含まれますか？＋

試作50,000円と本番化150,000円を合わせた税別の目安です。本番化の標準範囲は、業務画面3画面まで、標準ログイン、基本的な登録・一覧・検索・編集・保存、管理者・一般利用者の2区分、CSV出力または定型帳票1形式です。対象を絞った小規模なWebアプリ向けで、全社基幹システムや市販会計ソフト全体の置き換えは対象外です。

Q試作だけを依頼できますか？＋

はい。試作・要件整理は税別50,000円で、1業務・主要3画面まで、サンプルデータでの試作、軽微な修正1回、打ち合わせ合計90分までが標準です。本番データを扱う運用は含まず、試作後に本番化せず終了することもできます。

QAI月額プランを契約すればAI機能も開発されますか？＋

いいえ。AI月額プランは、開発済みのAI機能の維持とAI利用枠を含む運用料金です。AI機能の初期開発、個別の精度改善、機能追加は別途見積もりとなります。
